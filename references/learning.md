# 二、学习 · 4 个 Prompt

> 覆盖四种学习需求：听不懂概念（双层解释法）、想模仿好作品（反向拆解）、系统研究陌生领域（横纵分析法）、验证资料真伪（事实核查）。

---

## 1. 双层解释法

**适用场景**：用户说"这个概念我完全听不懂"。避免停留在"好像懂了"的类比层，真正讲清机制。

```
我想学习的是：【填写概念或问题】。请分两层解释：第一层，小白版。用生活化的语言和一个具体例子，让完全没有基础的人也能听懂。第二层，专业版。使用准确术语，讲清核心机制、适用边界和常见误解。最后请整理出：1. 列出小白说法与专业术语的对应关系；2. 我最容易理解错的地方；3. 3个用于检查我是否真正理解的问题。
```

---

## 2. 反向拆解

**适用场景**：看到一个优秀的产品/网页/方案/数据看板，想知道它到底好在哪、能学到什么。

```
我想拆解的优秀范例是：【粘贴产品页面、网页、方案、流程说明、数据看板或其他成品】。我想学会的是：【填写你希望从中学会什么】。请先用一句话说明它解决了什么问题，再反向拆解它为什么有效。重点分析：1. 它服务谁，目标是什么；2. 它采用了什么结构或流程；3. 哪些关键选择拉开了质量差距；4. 它的完成标准是什么；5. 哪些规律可以迁移，哪些细节只适合这个案例。最后请给我：1. 提炼3到5条可复用规律；2. 一份可以照着执行的操作清单；3. 一个最值得先尝试的小练习。
```

---

## 3. 横纵分析法

**适用场景**：深度、系统地研究一个陌生的产品/公司/人物/技术/行业。核心是两条轴——纵轴看它怎么走到今天（历史演化），横轴看它与竞品的差异（当下定位）。**须在联网环境下配合搜索/深度研究能力使用**，全程执行 `search-freshness.md` 时效核查协议，报告要求 8000～15000 字，分章交付（先提纲与核心结论，确认后逐章完成）。

```
研究对象是：【填写产品、公司、人物、技术、行业或事件】。请使用横纵分析法，对它完成一份可追溯的深度研究。研究截止时间为执行当天。纵向分析：1. 它在什么背景和需求下诞生，关键推动者是谁；2. 它经历了哪些重要转折、成功和失败；3. 哪些早期选择变成了今天的能力、路径依赖或包袱。横向分析：1. 选择最值得比较的对象，并说明为什么选它们；2. 用统一维度比较各自的强项、短板和独特性；3. 解释用户、客户或市场为什么选择它，又为什么放弃它。把两条轴合起来，继续判断：1. 过去形成的能力、路径依赖和约束会怎样影响未来；2. 未来最可能出现哪3条路径；3. 每条路径出现的前提和预警信号是什么。请遵守这些证据规则：1. 优先使用官方资料、原始数据、论文、财报和访谈等一手来源；2. 重要结论就近标注来源与日期，所有操作性结论（命令、配置、API 用法）必须额外标注适用版本与核查日期，格式为「适用于 vX.Y，核查于 YYYY-MM」；3. 事实、推断和观点分开写；4. 遇到冲突信息时并列呈现，找不到证据时明确写"暂未核实"，禁止编造来源。最后按以下顺序输出：核心结论、关键时间线、横向对比表、详细分析、未来判断、仍待确认的问题。报告总长控制在8000～15000字，按六节顺序分章交付：先输出核心结论与提纲供我确认，再逐章完成其余部分，每章2000～4000字；各节参考占比为核心结论10%、关键时间线15%、横向对比表15%、详细分析40%、未来判断15%、仍待确认的问题5%。语言尽量通俗，不要堆砌资料。
```

## 4. 事实核查

**适用场景**："这份资料里的说法到底是真的吗？"既可审查事实数据，也可审查别人的观点或方案。按笛卡尔式怀疑处理人类与 AI 的内容，对抗幻觉与愚昧之巅。核查涉及操作方法/版本/数据时，同步执行 `search-freshness.md` 时效核查协议。

```
我要核查的说法是：【粘贴观点、结论、数据或方案】。请先把它拆成：1. 可以被外部验证的事实；2. 从事实推出的结论；3. 其中包含的价值判断。对于事实部分，请联网核查来源、样本、时间和完整上下文，并标记为：1. 已证实；2. 基本成立，但需要收窄；3. 存在争议；4. 证据不足；5. 明显错误。每个标记都必须附上来源与发布日期，查不到可靠来源时如实标注「暂未核实」，禁止编造来源。凡属操作性结论（命令、配置、教程步骤），还须按当前最新版本验证其是否仍然有效，并落款「适用于 vX.Y，核查于 YYYY-MM」；已失效的写明失效原因与替代方法。在假设相关事实成立的情况下，继续检查：1. 这些事实能否推出当前结论；2. 是否藏着未经验证的假设；3. 是否混淆相关性和因果关系；4. 是否遗漏了其他解释或关键信息；5. 结论在什么条件下成立或失效。最后请输出：1. 哪些事实可信，哪些需要修正；2. 推理链中最关键的漏洞；3. 补强后的最合理版本；4. 我目前可以相信到什么程度。
```
