# 四、决策 · 2 个 Prompt

> 前面所有环节都在帮用户找到更多路径和信息量；当"两个答案都有道理"时，才轮到真正的决策工具。

---

## 1. 双向钢人论证

**适用场景**：用户已有候选答案但不知道选哪个；候选超过 2 个时，先按"可逆性×影响面"预筛出最强的 2 个再论证。与"帮你提出问题"的工具（如 grill me）底层逻辑不同——这是**做决策**用的：先把两个方向都钢人化到最强，再逼出关键分歧。

```
我需要做的决定是：【写清问题、候选选项、目标和现实约束】。先别急着回答，也别默认我已经把问题想清楚。如果候选超过两个，先用"可逆性×影响面"做快速预筛，淘汰明显较弱的选项，只保留最强的两个进入后续步骤。请先做一次双向钢人论证：1. 用最完整、有力的方式，重述我真正需要做出的选择；2. 分别给出支持两个方向的最强理由、适用条件、最大收益、最大风险，以及最难回答的反对意见；3. 找出双方真正的分歧、最可能改变结论的关键变量，以及还需要补充的信息；4. 只问我一个最可能改变结论的问题。等我回答以后，再给出明确判断、理由、适用条件和下一步行动。
```

---

## 2. 用最小实验替代空想

**适用场景**：继续纸上谈兵也不会更清晰的决定——需要迈出第一步拿现实反馈。让 AI 帮忙设计一个低成本、可逆的最小实验。

```
我正在纠结的是：【填写你的选择或想法】。请先找出这个决定背后最需要验证的3个假设，再选出最可能改变最终结论的那一个。围绕这个假设，帮我设计一个低成本、可逆、能在【填写你能接受的实验周期，例如7天】内完成的最小实验。请写清：1. 具体要做什么；2. 需要投入多少时间和资源；3. 观察什么指标；4. 什么结果支持继续；5. 什么结果提醒我停止；6. 实验结束后能获得什么新信息。最后告诉我，明天就能开始的第一个动作是什么。
```

## 两者的配合关系

双向钢人论证解决"想清楚"，最小实验解决"验证清楚"。若钢人论证后关键变量仍无法靠信息补齐，自然衔接到最小实验——把那个"最可能改变结论的关键变量"转化为实验要验证的假设。
