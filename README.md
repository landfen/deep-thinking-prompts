# Deep Thinking Prompts（深度思考 Prompt 工具箱）

> 12 个覆盖「问清问题 → 学习 → 解决问题 → 决策 → 认识自己」完整链路的深度思考 prompt 模板 + 1 套联网时效核查协议。整理自数字生命卡兹克文章《都Agent时代了，我还是想分享给你这12个我最常用的Prompt》（2026-08），并经专家团会诊两轮工程化优化。

## 这是什么

一个可直接安装到 AI 助手（WorkBuddy / Claude Code 等支持 Agent Skills 规范的环境）的技能包。安装后，AI 会根据你的问题自动路由到最合适的思考方法——你只管提问，它负责选对工具。

**v1.1.0 核心增强：联网检索时效核查协议（search-freshness）** —— 根治「AI 搜出过期答案，照做浪费几小时」的经典痛点。

## 12 个 Prompt 模板总览

| 阶段 | 模板 | 解决什么问题 | 交互模式 |
|---|---|---|---|
| 问清问题 | 苏格拉底式提问 | 问题混乱、说不清真正想问什么 | 多轮问诊（≤6 题） |
| 学习 | 双层解释法 | 完全听不懂某个概念 | 单轮输出 |
| 学习 | 反向拆解 | 看到好作品想模仿学习 | 单轮输出+追问 |
| 学习 | 横纵分析法 | 深度系统研究陌生领域 | 深度研究 ≥30 分钟 |
| 学习 | 事实核查 | 怀疑说法/数据/方案真伪 | 单轮核查 |
| 解决问题 | 专家会诊 | 复杂问题需要多视角权衡 | 单轮输出 |
| 解决问题 | 第一性原理 | 方案反复打补丁、想推倒重来 | 单轮输出 |
| 解决问题 | 跨领域借解 | 本行业无解、跨界找答案 | 单轮输出 |
| 决策 | 双向钢人论证 | 两个选项犹豫不决（>2 个自动预筛） | 两轮交互 |
| 决策 | 最小实验替代空想 | 纸上谈兵得不出结论 | 单轮输出 |
| 认识自己 | 挖掘隐藏天赋 | 弄清自己的天赋优势 | 多轮深访 ≤10 题 |
| 认识自己 | 人生设计术 | 规划职业/人生方向 | 多轮深访 6~9 题 |

组合链路示例：模糊想法 → 苏格拉底式提问 → 专家会诊 → 双向钢人论证 → 最小实验验证。

## 🛡 时效核查协议（search-freshness.md）—— v1.1.0 新增

为什么加这个？因为 AI 联网搜索有五大真实失效模式：

1. **拿搜索摘要直接定稿**——摘要没有日期版本号，2023 老教程被当现状（90% 过期答案的成因）
2. **SEO 老文霸屏**——前 3 条全是 2~3 年前的同质内容
3. **中文圈滞后+转载农场**——CSDN/公众号搬运两年前的英文教程还压过官方文档
4. **易变字段当稳定事实**——API 参数/价格/命令过期最快却当常识输出
5. **官方文档改版后旧 URL 仍被索引**

对应反制机制：

```text
T0 十秒分类      → 答案 12 个月后会不会变？敏感型走完整验证，钝感型零负担
五步时效验证     → 官方锚点 → 失效扫描 → 社区验尸 → 双源日期 → 版本落款
R1 禁止摘要定稿   → 操作性结论必须打开原文核对日期与版本号
中文特化         → 命中转载农场/滞后信号立即切英文重搜
L0~L3 分级投入   → 定义不搜；查版本单轮；教程两轮；生产操作多轮交叉
```

输出侧三件套：

- **🟢🟡🔴 时效红绿灯**：答案第一行先告诉你能不能信
- **⏱ 30 秒预验**：高危步骤前先跑一条无害命令确认版本匹配
- **失败兜底**：搜不到新答案就明说，拆「仍有效/已变/出路」三段，绝不硬答

## 设计原则

- **奥卡姆剃刀优先**：简单事实性问题不套模板、不启动问诊
- **可判定规则 > 空泛原则**：所有规则写成 `if 条件 then 必须动作`
- **长文分章交付**：万字交付物先提纲后逐章，拒绝单轮注水与截断
- **语言跟随用户**：全程以用户所用语言输出
