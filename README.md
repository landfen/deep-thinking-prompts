> v2.0.0。前身 deep-thinking-prompts v1.3.0（13 模板）推倒重构而来：从「用户手动点名的模板箱」进化为「AI 干活时自动调用的思维引擎」。

## 这是什么

一个以经典思维工具为内核的自动思维引擎。三个最终目的：**检索答案更准、问答切中要害、决策建议不平庸**。

安装后不需要点名调用--AI 接到任务后自动执行六步引擎：

## 快速开始

```bash
# 克隆到 WorkBuddy 用户级技能目录
git clone https://github.com/landfen/deep-thinking-prompts.git \
  ~/.workbuddy/skills/deep-thinking
```

重启会话后即生效。触发方式：直接描述需求，或 @skill:deep-thinking。

> 仓库名沿用 v1.x 的 `deep-thinking-prompts`，但目录请命名为 `deep-thinking`——skill 名由 `SKILL.md` frontmatter 的 `name` 字段决定，与目录名保持一致即可正确加载。

```
任务输入 -> ① 分级判定（轻/中/重三级火力）
         -> ② 环节诊断（拆解/检索/聚合，哪环弱？）
         -> ③ 按层挂载工具（诊断哪环弱挂哪层，不全家桶）
         -> ④ 要事暂停（P1 真问题确认 / P2 决策关键变量）
         -> ⑤ 执行（联网检索走双保险协议）
         -> ⑥ 带落款交付（工具 + 诊断 + 置信度 + 缺口，全级显示）
```

## 21 件思维工具 · 四层结构

| 层 | 工具 | 治什么 |
|---|---|---|
| 一、理解问题层 | 第一性原理★、奥卡姆剃刀★/汉隆剃刀、二阶思维★、5 Whys、MECE、假设澄清、后向推理、苏格拉底式提问 | 问题没问对 |
| 二、检索质量层 | SIFT 横向阅读、贝叶斯更新、时效核查(T0/R1-R5)、价格专项(P1-P4)、刨根问底、横纵分析法、事实核查 | 检索不准不深 |
| 三、回答质量层 | 双层解释法、多专家会诊、反向拆解、跨领域借解 | 回答停在表面 |
| 四、决策质量层 | 逆向思维★、机会成本★、安全边际★、可逆性测试、WRAP、预验尸、双向钢人论证、最小实验 | 建议平庸和稀泥 |

★ = 用户核心 6 把。决策类重任务强制执行「逆向压测 -> 机会成本 -> 安全边际」三连。

## 设计原则

- **全程自动 + 省 token**：分级火力，轻任务剃刀直答，重任务满配，不全家桶
- **诊断透明**：所有级别显示引擎诊断落款；重任务四行版（级别+诊断/工具/置信度/缺口）
- **要事暂停**：重任务仅在 P1（真问题确认）与 P2（决策关键变量 ≤3 问）暂停，其余黑盒直出
- **可判定规则 > 空泛原则**：继承 v1.3.0 的 if-then 规则风格
- **用户点名优先于自动诊断**

## 升级说明（v1.1.0 -> v2.0.0）

> v1.2.0（刨根问底协议）与 v1.3.0（价格/活动 P1-P4 规则）当时只更新了文件未打 tag，本次 v2.0.0 一并纳入版本历史。

- 推倒重构：13 个手动模板 -> 六步自动引擎（分级/诊断/挂载/暂停/执行/落款）
- 新增 15 件思维工具定义（toolbox.md §1-§21），核心 6 把（第一性原理/二阶/逆向/奥卡姆/机会成本/安全边际）+ SIFT/贝叶斯/MECE/5 Whys/WRAP/预验尸/可逆性测试等
- 三级火力（轻/中/重）+ 五维升重判定
- 两个暂停点（P1 真问题、P2 关键变量）
- 全级诊断落款（重任务四行版）
- 双层解释法与多专家会诊点名保留；时效核查与刨根问底协议整体继承
